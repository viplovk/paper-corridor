# 🏛️ Paper Corridor — Infinite Sketch Gallery

> *"Walk forward into the graphite void. The vanishing point never arrives."*

An interactive, hand-drafted 3D corridor built with pure perspective mathematics and canvas rendering. Designed to mimic the tactile, melancholic feel of raw pencil sketches, loose flying sheets, and infinite architectural arches.

---

### 👁️ Preview & Experience

- **Live Demo:** [Infinite Sketch Gallery](https://paper-corridor.vercel.app/)
- **Engine:** Custom Pencil Graphite Engine (Canvas 2D / WebGL)
- **Target Frame Rate:** 60 FPS

---

### ✨ Features

- ✏️ **Hand-Drafted Aesthetic:** Dynamic graphite strokes, textured paper grain, and architectural line work.
- 📐 **Central Vanishing Point:** Math-driven 1-point infinite perspective illusion that stretches seamlessly as you walk.
- 📜 **Atmospheric Elements:** Floating sketch sheets, hanging industrial lamps, and gallery portraits dynamically loaded along the corridor walls.
- 🎥 **Mouse Look & Pointer Lock:** Free look navigation allowing real-time viewing of framed art and subtle room details.
- 🎧 **Ambient Audio:** Minimalist tactile hum and page-rustling atmosphere.

---

### 🕹️ Controls

| Action | Control |
| :--- | :--- |
| **Look Around** | `Mouse Movement` (Click canvas to toggle) |
| **Walk Forward** | `W` / `Arrow Up` / `Scroll Down` |
| **Step Back** | `S` / `Arrow Down` / `Scroll Up` |
| **Pause / Resume** | `P` or Top-Right Menu |
| **Mute Sound** | Sound Toggle in HUD |

---

### 🛠️ Tech Stack

- **Framework:** Next.js / Vanilla Canvas Architecture
- **Rendering:** Custom Perspective Projection & Line-Shading Engine
- **Styling:** Minimalist Monospaced HUD (Tailwind CSS)
- **Deployment:** Vercel

### 🚀 Local Development

Clone the repository and run the development server:

```bash

# Navigate into directory
cd paper-corridor

# Install dependencies
npm install

# Start development server
npm run dev
